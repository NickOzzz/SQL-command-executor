In order to run the app, build it using *.vcxproj* files, go to x64/Debug and run ./CPPSQL.exe

You can use x64/Debug/appsettings.json file for the configuration where database url, username and password have to be modified 
or you can choose to provide these details in the CLI when running the app.

Prebuilt production binary is located on the external drive: https://drive.google.com/drive/folders/1fnO52vESkFPe0p6l0McF96d9sE1eSAyX
